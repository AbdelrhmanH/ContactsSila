# 01 — التهيئة الأولى والبطاقة التعريفية

> المرجع: [PRD §3](../PRD.md#3-التهيئة-الأولى-والبطاقة-التعريفية-onboarding) · المرحلة: 1 (ضيف) / 2 (تسجيل وبطاقة)

## الشاشات
1. **ترحيب** (3 شرائح: نظّم · خدمات حية · أرحام) + "ابدأ".
2. **شرح صلاحية جهات الاتصال** ← طلب الصلاحية.
3. **تسجيل الدخول** (رقم الهاتف + OTP) أو **"تخطي الآن"**.
4. **استخدام الرقم:** 👤 شخصي فقط · 💼 للعمل/تقديم خدمة · 🔄 للاثنين (SilaActionSheet بأسلوب البطاقات).
5. **رقم آخر؟** إضافة رقم ثانٍ وتحديد استخدامه.
6. **بطاقة العمل** (إن وُجد رقم عمل): نوع الخدمة، اسم النشاط، المدينة/الموقع، أوقات العمل، وصف.
7. **مجال العمل والاهتمامات** (Chips متعددة الاختيار).
8. **أهم 5 أشخاص** (بحث + اختيار + صلة القرابة السريعة).
9. **جارٍ التنظيم…** (الفلترة الذكية تبدأ في الخلفية) ← الرئيسية.

## قصص المستخدم
- **US-01.1** كمستخدم جديد، أريد تجربة التطبيق بدون تسجيل، حتى أقرر إن كان مفيداً.
- **US-01.2** كمستخدم، أريد تحديد أن رقمي للعمل والشخصي معاً، حتى يتعامل التطبيق معه بشكل صحيح.
- **US-01.3** كصاحب خدمة، أريد إنشاء بطاقة عمل، حتى يظهر رقمي موثقاً في الدليل.
- **US-01.4** كمستخدم، أريد مشاركة بطاقتي بـ QR، حتى تُحفظ عند الآخر بالتصنيف الصحيح.

## معايير القبول
- [ ] كل خطوة بعد الصلاحية قابلة للتخطي، ويمكن إكمالها لاحقاً من الإعدادات.
- [ ] التخطي يضع `isGuest = true`؛ لا طلبات كتابة للسحابة.
- [ ] OTP: إعادة الإرسال بعد 60 ث، التحقق التلقائي (Android SMS Retriever) حيث أمكن.
- [ ] عند اختيار "شخصي فقط" لا تظهر خطوة بطاقة العمل.
- [ ] إنشاء بطاقة عمل برقم الحساب ← الخدمة تظهر VERIFIED خلال ثوانٍ.
- [ ] إن كان رقم العمل مختلفاً عن رقم الحساب ← يُطلب OTP له قبل التوثيق.
- [ ] أهم 5 أشخاص يُصنفون "عائلة" ويُضافون لأرحام بوتيرة أسبوعية افتراضياً (قابلة للتعديل).
- [ ] Onboarding لا يتكرر بعد إكماله (`onboardingCompleted`).
- [ ] QR يحتوي رابطاً `https://sila.app/p/{cardId}` + vCard احتياطي؛ المسح من خارج التطبيق يفتح المتجر أو الويب.
- [ ] مسح QR داخل التطبيق ← معاينة البطاقة ← "حفظ" بالتصنيف المقترح من صاحبها.

## الحالات الحدية
- رفض صلاحية جهات الاتصال ← المتابعة مع شاشة فارغة توضيحية.
- فشل OTP / لا إنترنت ← رسالة + خيار المتابعة كضيف.
- المستخدم يسجّل لاحقاً من الدليل ← يعود لنفس المكان بعد التسجيل.
