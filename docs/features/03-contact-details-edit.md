# 03 — تفاصيل جهة الاتصال والإضافة/التعديل

> المرجع: [PRD §5–6](../PRD.md#5-صفحة-تفاصيل-جهة-الاتصال)

## أ. صفحة التفاصيل

### التخطيط
```text
←                                    ☆  ✎  ⋯
            (  صورة كبيرة  )
             د. أحمد علي
         طبيب أسنان · عيادة النور
      [ ❤ عائلة · خال ]  [ ✔ موثق ]
   [📞 اتصال] [💬 رسالة] [🎥 فيديو] [✉ بريد]
─────────────────────────────────────────────
الأرقام      +20 100 123 4567  جوال (افتراضي)  📞 💬
التطبيقات    [WhatsApp] [Telegram] [Signal]
أرحام        الهدف: أسبوعياً · آخر اتصال قبل 9 أيام 🔴
السجل        ↗ أمس 4:12م · 6د | ↙ الإثنين · 2د | ✕ فائتة
البريد / العنوان / التواريخ / الشركة / الملاحظات / حقول مخصصة
الحساب       Google · ahmed@gmail.com
```

### معايير القبول
- [ ] انتقال Shared Element للصورة والاسم من القائمة.
- [ ] الأزرار السريعة تستخدم الرقم الافتراضي؛ ضغطة مطولة لاختيار رقم/شريحة.
- [ ] Connected Apps تظهر فقط إن كان التطبيق مثبتاً والرقم مسجلاً فيه (أندرويد: RawContacts؛ iOS: Scheme متاح).
- [ ] السجل يعرض آخر 20 تفاعلاً لكل أرقام جهة الاتصال + "عرض الكل".
- [ ] الحقول الفارغة لا تظهر.
- [ ] نقرة على رقم = اتصال، مطولة = نسخ؛ عنوان = خرائط؛ بريد = تطبيق البريد؛ رابط = متصفح.
- [ ] قائمة "⋯" عبر `SilaActionSheet`:

| العنصر | العنوان الفرعي | المنصة |
|---|---|---|
| مشاركة | vCard أو نص أو QR | الكل |
| إضافة إلى الشاشة الرئيسية | اختصار للاتصال المباشر | Android |
| نقل إلى حساب آخر | الهاتف ↔ Google | Android (iOS محدود) |
| النغمة المخصصة | | Android |
| تحويل للبريد الصوتي | | Android |
| تغيير التصنيف | | الكل |
| إعدادات أرحام | القرابة والوتيرة | الكل |
| حظر الرقم | | الكل (حسب القدرة) |
| حذف (أحمر) | يمكن التراجع خلال 5 ثوانٍ | الكل |

- [ ] الحذف: Snackbar "تراجع" — التنفيذ الفعلي بعد انتهاء المهلة.
- [ ] النقل بين الحسابات: نسخ إلى الحساب الهدف ثم حذف من المصدر، مع الحفاظ على بيانات صِلَة.

## ب. صفحة الإضافة/التعديل

### التخطيط
```text
✕  جهة اتصال جديدة                       حفظ
            ( 📷 إضافة صورة )
التصنيف  [عائلة][أصدقاء][عمل][خدمات][طوارئ]
الاسم الأول  [            ]
اسم العائلة  [            ]
الهاتف      [+20 ▾][            ] [جوال ▾]  ⊕
[⌄ إظهار المزيد]
  ├ الاسم: بادئة · أوسط · لاحقة · كنية · حفظ باسم · نطق
  ├ البريد ⊕ · العنوان ⊕ · الموقع ⊕
  ├ الشركة · القسم · المسمى الوظيفي ⊕
  ├ تواريخ هامة ⊕ · العلاقات ⊕
  ├ ملاحظات · حقول مخصصة ⊕
  ├ النغمة
  ├ [عائلة] القرابة · الوتيرة
  ├ [خدمات] نوع الخدمة · أوقات العمل · مشاركة مع الدليل
  └ حفظ في: [Google ahmed@ ▾]
```

### قصص المستخدم
- **US-03.1** أريد إضافة اسم برقم وتصنيف فقط بسرعة.
- **US-03.2** أريد عند الحاجة ملء كل الحقول المتقدمة كما في Google Contacts.
- **US-03.3** أريد أن ينبهني التطبيق إن كان الرقم محفوظاً مسبقاً أو مسجلاً في الدليل.

### معايير القبول
- [ ] الحد الأدنى للحفظ: اسم **أو** رقم.
- [ ] التصنيف: إن لم يُختر، يظهر عند الحفظ Sheet سريع "صنّف قبل الحفظ" مع خيار "لاحقاً".
- [ ] "إظهار المزيد" يتذكر حالته؛ عند التعديل تُفتح المجموعات التي تحتوي بيانات تلقائياً.
- [ ] الحقول المتعددة: إضافة/حذف/إعادة ترتيب، ونوع لكل عنصر مع "مخصص".
- [ ] تطبيع الرقم مع مفتاح الدولة الافتراضي حسب الشريحة/اللغة، والتحقق من الصلاحية بدون منع الحفظ.
- [ ] فحص الرقم (Debounce 400ms): محلياً ثم في الدليل — حسب مخطط [PRD §6.3](../PRD.md#63-فحص-الرقم-أثناء-الإضافة-منطق-الخدمات).
- [ ] اختيار "شخصي" لرقم موجود في الدليل ← حفظ محلي، لا Outbox.
- [ ] تاريخ ميلاد لعضو في العائلة ← يُسجل كمناسبة في أرحام تلقائياً.
- [ ] الصورة: كاميرا / معرض / إزالة؛ قص مربع؛ ضغط ≤ 512px.
- [ ] الخروج مع تغييرات غير محفوظة ← تأكيد.
- [ ] الحفظ يكتب في دفتر الهاتف (الحقول القياسية) و Room (بيانات صِلَة) في عملية واحدة؛ الفشل يتراجع عن الاثنين.

### ربط الحقول بالمنصات
| الحقل | Android `ContactsContract.Data` | iOS `CNContact` |
|---|---|---|
| Prefix/First/Middle/Last/Suffix | `StructuredName` | `namePrefix`, `givenName`, `middleName`, `familyName`, `nameSuffix` |
| Nickname | `Nickname` | `nickname` |
| File as | `StructuredName.DISPLAY_NAME` / ترتيب | ترتيب العرض فقط (Room) |
| Phonetic | `PHONETIC_*` | `phonetic*Name` |
| Company/Department/Job | `Organization` | `organizationName`, `departmentName`, `jobTitle` |
| Phones/Emails/Addresses | `Phone`, `Email`, `StructuredPostal` | `phoneNumbers`, `emailAddresses`, `postalAddresses` |
| Dates | `Event` | `birthday`, `dates` |
| Relations | `Relation` | `contactRelations` |
| Websites | `Website` | `urlAddresses` |
| Notes | `Note` | `note` (يتطلب entitlement خاص — يُحفظ في Room بديلاً) |
| Custom fields | MIME مخصص `vnd.sila.custom` أو Room | Room |


## أنماط التفاعل المستخدمة
> المرجع: [DESIGN_SYSTEM.md §5.2](../DESIGN_SYSTEM.md#52-أنماط-التفاعل-المتقدمة-مستوحاة-من-المراجع)

| النمط | الموقع |
|---|---|
| **النمط 1 — بطاقات قابلة للتوسع** | "إظهار المزيد" يتمدد بحركة `animateContentSize` لكشف الحقول المتقدمة · إضافة رقم/بريد جديد ينزلق بسلاسة |
| **النمط 2 — إدخال → رقاقات** | الوسوم المخصصة (Custom Tags): كتابة "زميل جامعة" → Enter → يتحول لـ Chip ملون تحت الاسم مع × للحذف |
| **النمط 2 — إدخال → رقاقات** | مشاركة رقم خدمي مع أشخاص محددين: إيقاف "مشاركة للعامة" → ينبثق حقل "أضف شخصاً" → يتحول لـ Chip |
