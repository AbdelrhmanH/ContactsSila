# 05 — دليل الخدمات الحي

> المرجع: [PRD §9](../PRD.md#9-الصفحة-2-دليل-الخدمات-الحي) · الخلفية: [BACKEND_FIREBASE.md](../BACKEND_FIREBASE.md)

```text
┌ دليل الخدمات                    📍 السويس ▾ ┐

│ ┌────┐┌────┐┌────┐┌────┐                    │
│ │💊  ││🔧  ││🍽  ││🚑  │  ← شبكة التصنيفات  │

│ ┌ 🏪 شركة الأمانة للجملة  ✔ موثق  🔥     📞 ┐│
│ │ مورد أغذية · 2.4 كم · متاح الآن          ││
│ │ مُفضل لدى 120 مستخدم                     ││
│ └──────────────────────────────────────────┘│

│ └──────────────────────────────────────────┘│
│ [ + أضف نشاطك التجاري للدليل ]              │
│ ┌ سجّل مجاناً لإضافة الخدمات والتقييم  › ┐  │ ← للضيف
├─────────────────────────────────────────────┤
```

## قصص المستخدم
- **US-05.1** كضيف، أريد إيجاد صيدلية قريبة والاتصال بها فوراً.
- **US-05.2** أريد أن أثق أن الرقم يعمل (شارة + مؤشر ثقة).
- **US-05.3** كتاجر تجزئة، أريد رؤية تجار الجملة والموردين أولاً.
- **US-05.4** أريد أن يتحدث رقم الخدمة عندي تلقائياً إن تغير.
- **US-05.5** أريد تقييم الخدمة بنقرة بعد أول تعامل، دون إزعاج متكرر.
- **US-05.6** أريد الإبلاغ عن رقم لا يعمل.

## معايير القبول

### العرض والبحث
- [ ] الضيف يرى الدليل العام كاملاً (COMMUNITY + VERIFIED) ويتصل مباشرة.
- [ ] الخدمات الشخصية للمستخدم تظهر في "خدماتي" فقط.
- [ ] الترتيب الافتراضي: التطابق مع المهنة ← VERIFIED ← trustScore ← المسافة.
- [ ] الـ Chips والشبكة تُبنى من `interestTags` + `professions.suppliers` (للمسجلين)؛ الضيف يرى الافتراضي.
- [ ] النطاق: خدمات يومية = إعداد المستخدم (افتراضي 5 كم)؛ B2B = المدينة/المحافظة + المراكز التجارية.
- [ ] بدون موقع ← اختيار المدينة يدوياً.
- [ ] "متاح الآن/مغلق" من `workingHours` بتوقيت الجهاز.
- [ ] البطاقات تعمل Offline من Cache Room مع شريط "آخر تحديث".
- [ ] خدمة `possiblyBroken` تظهر بتحذير رمادي وتنزل في الترتيب.

### الحفظ والتحديث
- [ ] "حفظ" من بطاقة الخدمة ← جهة اتصال SERVICES مرتبطة بـ `linkedServiceCloudId` + اشتراك FCM Topic.
- [ ] عند تحديث الرقم سحابياً ← يتحدث في Room خلال دقائق (FCM) أو عند الفتح؛ وإن فعّل المستخدم الخيار يتحدث في دفتر الهاتف مع إشعار "تم تحديث رقم صيدلية الشفاء".

### المساهمة (مسجّل)
- [ ] حفظ رقم جديد كخدمة ← Outbox `SERVICE_SUGGESTION` ← Toast "شكراً لمساهمتك".
- [ ] الضيف ← حفظ محلي فقط + Login Wall إن حاول "مشاركة مع الدليل".

### التقييم والثقة
- [ ] بعد مكالمة صادرة لخدمة (ليست عائلة/أصدقاء) ≥ 30 ث ولم تُقيَّم ← إشعار/Sheet: "كيف كانت تجربتك مع …؟" 🤩 🙂 😞 + تعليق اختياري.
- [ ] يظهر مرة واحدة فقط لكل خدمة؛ "ليس الآن" يؤجله لمرة واحدة.
- [ ] مكالمات لاحقة ← `CALL_SIGNAL` فقط (إشارة واحدة يومياً) بدون سؤال.
- [ ] يحترم إعداد "التقييم السريع" وأوقات الهدوء.
- [ ] الضيف: يظهر السؤال، والنقر ← Login Wall، وبعد التسجيل يُرسل التقييم المعلّق.
- [ ] العرض: "مُفضل لدى X مستخدم" عند X ≥ 10؛ "نسبة العودة Y%" عند uniqueCallers ≥ 20؛ 🔥 حسب `isHot`.

### البلاغات
- [ ] "⋯ ← الإبلاغ عن رقم لا يعمل" مع حقل اختياري للرقم الجديد (مسجّل فقط).
- [ ] "هذا رقمي الشخصي — أزله" ← OTP ← إزالة وحظر إعادة الاقتراح.

### سجل النزاعات (Dispute Log)
> المرجع: [PRD §9.8](../PRD.md#98-سجل-النزاعات-dispute-log)

- [ ] زر "📝 توثيق نزاع" في صفحة تفاصيل الخدمة (مسجّل فقط).
- [ ] نموذج: وصف نصي (حتى 500 حرف) + حتى 3 صور (WebP ≤ 256px).
- [ ] الحفظ في Room (`dispute_logs`) فوراً ← مزامنة عبر Outbox عند الإنترنت.
- [ ] حالة: `OPEN` → `RESOLVED` → `ARCHIVED` — يُديرها المستخدم يدوياً أو تلقائياً (90/180 يوم).
- [ ] صور النزاع: Firebase Storage بـ TTL 14 يوماً بعد الأرشفة.
- [ ] خاص بالمستخدم — لا يظهر لمزود الخدمة ولا للآخرين.
- [ ] "نزاعاتي" تظهر كقسم في "خدماتي" أو في شاشة فرعية.
- [ ] Empty state: "لا نزاعات — نأمل ألا تحتاج هذه الميزة أبداً 🌿".

### بطاقة العمل
- [ ] "أضف نشاطك" ← تسجيل (إن لزم) ← نموذج البطاقة ← VERIFIED.

### لوحة تحكم مزود الخدمة (Pro — المرحلة 4)
> المرجع: [PRD §20.1](../PRD.md#201-لوحة-تحكم-مزود-الخدمة-service-provider-dashboard) · التصميم: [pro-dashboard-bento.jpg](../design-references/pro-dashboard-bento.jpg)

- [ ] الشريط العلوي: محدد النطاق الزمني + إشعارات 🔔 + أيقونة البروفايل.
- [ ] بطاقة الأداء العام: مؤشر الثقة الدائري + 3 Sparklines (ظهور/زيارات/حفظ) + سطر الاتجاه.
- [ ] شبكة Bento Grid (6 بطاقات): مكالمات واردة · تقييمات إيجابية · متوسط مدة المكالمة · مشاركات · عملاء فريدون · نسبة العودة.
- [ ] بطاقات التحكم السريع: متاح الآن (Toggle يتزامن مع أوقات العمل) · الظهور في الدليل · أوقات العمل (النمط 1) · رسالة الرد التلقائي.
- [ ] Feature Flag: `pro_dashboard_enabled` عبر Remote Config.

## حالة الكشف عن نهاية المكالمة
| المنصة | الآلية |
|---|---|
| Android | `TelephonyCallback.CallStateListener` (API 31+؛ `PhoneStateListener` على 26–30) — IDLE بعد OFFHOOK + مدة تقريبية بقياس OFFHOOK→IDLE للمكالمات التي بدأت من التطبيق؛ لا قراءة لسجل المكالمات ([ADR-0006](../adr/0006-call-log-strategy.md) مقبول: بدون `READ_CALL_LOG`) |
| iOS | `CXCallObserver` أثناء عمل التطبيق؛ وإلا عند العودة للتطبيق (`scenePhase == .active`) بعد بدء اتصال من التطبيق |
