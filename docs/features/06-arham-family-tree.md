## قصص المستخدم
- **US-06.1** أريد معرفة من يجب أن أتصل به الآن دون التفكير.
- **US-06.2** لا أريد تسجيل مكالماتي يدوياً.
- **US-06.3** أريد أن أشعر بالإنجاز عند التواصل، لا بالذنب عند التقصير.
- **US-06.4** أريد تذكيراً في وقت مناسب لا أثناء العمل.
- **US-06.5** أريد رؤية عائلتي كشجرة والاتصال من خلالها.

## معايير القبول

### القائمة المرقمة
- [ ] الترتيب تنازلياً حسب `urgency`؛ الترقيم 01، 02… يعكس الأولوية.
- [ ] الحالة واللون: ≥1.0 🔴، 0.7–1.0 🟡، <0.7 🟢 — مع نص بجانب اللون دائماً.
- [ ] النص الفرعي ديناميكي: "مر N يوماً منذ آخر اتصال" / "باقي N يوم على اتصالك الأسبوعي" / "تواصلت أمس" / "لم تتصل بعد".
- [ ] زر 📞 ملون بالحالة = اتصال مباشر (تسجيل `IN_APP` call event).
- [ ] لم يتصل أبداً ← يظهر في الأعلى بنص "لم تتصل بعد".
- [ ] OCCASIONS ← لا تدخل في الترتيب، تظهر فقط قبل المناسبة.
- [ ] المتوقف مؤقتاً (`pausedUntil`) ← مخفي مع عداد "3 متوقفون".
- [ ] نقرة على الاسم ← Kinship Setup Sheet / التفاصيل.

### اللوحة العلوية
- [ ] الفترة: هذا الأسبوع / هذا الشهر (من التفضيلات) مع وقت الانتهاء.
- [ ] المنصة: أعلى 3 حسب عدد المكالمات الناجحة ثم المدة في الفترة؛ أقل من 3 ← أماكن فارغة لطيفة "تواصل لتظهر هنا".
- [ ] الإحصائيات: إجمالي المكالمات العائلية، أطول مكالمة، أقارب تواصلت معهم/الإجمالي.
- [ ] تحقيق الأهداف = نسبة الأقارب (غير OCCASIONS وغير المتوقفين) في حالة OK.
- [ ] البطاقة السفلية: أقرب مناسبة خلال 7 أيام، وإلا رسالة تحفيزية.
- [ ] Badge شريط التنقل = عدد 🔴.

### التتبع
- [ ] مكالمة صادرة/واردة بمدة > 0 لأي رقم من أرقام القريب ← `lastContactedAt = max(...)`.
- [ ] مصادر الأحداث حسب [ADR-0006](../adr/0006-call-log-strategy.md): `CALL_LOG` (إن سُمح) · `IN_APP` · `OBSERVER` · `MANUAL`.
- [ ] تأكيد يدوي (حين لا يتوفر السجل): عند العودة للتطبيق بعد اتصال من داخله ← "هل تم التواصل مع عمك أحمد؟ [نعم] [لم يرد]"؛ وزر "تواصلت معه" في Sheet القريب.
- [ ] واتساب/مكالمات الإنترنت: زر "تواصلت عبر تطبيق آخر" يسجل `MANUAL`.

### الإشعارات
- [ ] إشعار واحد يومياً بحد أقصى (قابل للتعديل) في الوقت المفضل، يجمع: "عمك أحمد يفتقدك (+2 آخرون)".
- [ ] أزرار الإشعار: اتصال الآن · ذكّرني غداً.
- [ ] لا إشعار في أوقات الهدوء (يؤجل لنهايتها).
- [ ] إشعار المناسبة صباح اليوم نفسه (+ قبلها بيوم اختيارياً).
- [ ] قناة إشعارات مستقلة "أرحام" (Android).

### المكافأة
- [ ] عند تحول قريب من 🔴 إلى 🟢 أثناء غياب المستخدم ← عند الفتح: حركة انتقال البطاقة + Confetti مرة واحدة + رسالة "أحسنت! وصلت عمك أحمد ❤".
- [ ] يحترم "إظهار الاحتفال" و"تقليل الحركة".

### أتمتة الوصال (In-App Automation)
> المرجع: [PRD §10.8](../PRD.md#108-أتمتة-الوصال-in-app-automation)

- [ ] زر "⏰ جدولة تواصل تلقائي" في Kinship Setup Sheet أو بطاقة القريب.
- [ ] اختيار النوع: رسالة داخلية (In-App) أو رنة تلقائية.
- [ ] الجدولة: يومي · أسبوعي · أيام محددة · شهري · مرة واحدة + تحديد الوقت.
- [ ] **رسالة داخلية:** تحرير نص مخصص ← إرسال عبر FCM (إن كان المستقبِل مستخدم صِلَة) ← وإلا Smart Fallback (Pre-fill واتساب أو فتح شاشة SMS بالنص).
- [ ] **رنة تلقائية:** `ACTION_CALL` في الوقت المحدد ← إنهاء بعد 15 ثانية إن لم يُرد ← لا تكرار تلقائي (ليست طوارئ).
- [ ] تبويب "الرسائل" في أرحام: صندوق وارد/صادر مع ردود سريعة (❤️ 🤲 👍 😊).
- [ ] إدارة الجداول المفعّلة: قائمة مع Toggle تفعيل/تعطيل + تعديل + حذف.
- [ ] بدون إنترنت: الرسائل تُحفظ في Outbox وتُرسل عند الاتصال.
- [ ] يحترم أوقات الهدوء.

### رنين الطوارئ المتواصل
> المرجع: [PRD §10.9](../PRD.md#109-رنين-الطوارئ-المتواصل-emergency-ringing)

- [ ] يظهر **فقط** في تفاصيل جهة اتصال مصنفة `EMERGENCY`.
- [ ] زر "🚨 رنين طوارئ" مع تحذير قبل التأكيد.
- [ ] أندرويد: حلقة اتصال تلقائية (CALL → IDLE → 5 ثوانٍ → CALL) حتى الرد أو الإيقاف أو 10 محاولات.
- [ ] iOS: إرسال Critical Alert عبر FCM (إن كان المستقبِل مستخدم صِلَة) + فتح `tel:` URL متكرر.
- [ ] خيار تشغيل/إيقاف الميكروفون أثناء الرنين.
- [ ] Rate limit: 3 جلسات / 24 ساعة.
- [ ] يتوقف فوراً عند كشف حظر (`isBlocked`).
- [ ] Notification مستمرة (Foreground Service) أثناء الجلسة مع زر "إيقاف".

### Kinship Setup Sheet (`SilaActionSheet`)
- [ ] الخطوة 1: القرابة (قائمة مجمعة: الأصول / الإخوة والأبناء / جهة الأب / جهة الأم / أخرى).
- [ ] الخطوة 2: الوتيرة مع وصف: "يومياً — للوالدين والمقربين جداً" … مع ✔ للمحدد.
- [ ] اقتراح وتيرة افتراضية حسب القرابة (أب/أم: يومياً، إخوة: أسبوعياً، أعمام/أخوال: كل أسبوعين، أبناء العم: شهرياً).
- [ ] اختياري: المناسبات، الربط بقريب آخر (ابن عمي ← عمي)، إيقاف مؤقت.

### شجرة العائلة
- [ ] مستويات: الأجداد ← الوالدان + الأعمام/العمات (جهة الأب) + الأخوال/الخالات (جهة الأم) ← المستخدم + الإخوة ← الأبناء؛ أبناء العم تحت آبائهم إن رُبطوا، وإلا في مجموعة "أبناء العمومة".
- [ ] عقدة = دائرة صورة/حرف + الاسم + حلقة بلون الحالة.
- [ ] Pinch-zoom و Pan؛ "توسيط عليّ".
- [ ] نقرة = Sheet: اتصال / التفاصيل / تعديل القرابة.
- [ ] عقدة فارغة "+" لإضافة قريب في موقع ناقص.
- [ ] الرسم: Compose `Canvas` للخطوط + `Layout` مخصص؛ SwiftUI `Canvas` + `GeometryReader`.

### أرحام Widget (Android Glance + iOS WidgetKit)
> المرحلة: 1-2 (بعد اكتمال أرحام الأساسي)

- [ ] **Small Widget (2×2):** عدد الأقارب في 🔴 + "X أقارب ينتظرونك" + نقرة → فتح أرحام.
- [ ] **Medium Widget (4×2):** أعلى 3 أقارب حسب Urgency — الاسم + القرابة + أيام الانقطاع + زر اتصال مباشر.
- [ ] **Large Widget (4×4):** نفس Medium + شريط التقدم + إحصائيات مختصرة.
- [ ] التحديث: كل 30 دقيقة (`TimelineProvider` iOS / `GlanceAppWidget` Android) + عند تغيّر البيانات.
- [ ] Android: `GlanceAppWidget` مع `GlanceModifier` — يقرأ من Room مباشرة.
- [ ] iOS: `TimelineProvider` + App Group لمشاركة البيانات مع التطبيق الرئيسي.
- [ ] يحترم الوضع الداكن + RTL + أحجام الخطوط الكبيرة.
